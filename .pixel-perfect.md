# Design context for pixel-perfect

better-answers is a cited, permission-aware knowledge product for UK SMBs, used at work by Admins, Editors and Viewers, and held to WCAG 2.2 AA (`apps/web/AGENTS.md`).

Its design system is `packages/design-system/readme.md`, the `better-answers-design` skill. Read it before any design work. It sets one direction for every page, so where a pixel-perfect skill's defaults differ from it, on palette, fonts, type sizes and weights, motion, corners, borders or components, the readme wins.
