**D2 — `redaction` is a package, not a file.** The spec says *one module*; six recognisers, the descriptors, the pins, the pseudonyms and the officer post-pass in one file would be a thousand-line file the duplication gate reads badly (H5). **Default: `src/better_answers_worker/redaction/` with `__init__.py` as the one public face** — one import name, `better_answers_worker.redaction`, one public function, the internals reachable only through it, which is the deep module the spec asks for. **D3 — a health cue's sentence is withheld, not merely flagged.** Research 65's custom 3 says the cue "only raises a `special_category` finding for review — never an automatic redaction". The spec's always tier and the `redaction` fixture say the always set — special-category cues at sentence level included — is withheld as `[withheld]`. The authority order puts the fixture and the spec above research. **Default: the sentence is replaced by `[withheld]` and the verdict narrows.** Acceptance line 5 asks only for the flag and the verdict, so a reversal costs a line.

**D4 — what a suppression does to a span.** The rows say *the identifiers to keep out on reprocess*; the seam has to decide what "kept out" looks like in text. **Default: a suppressed identifier's span is raised at the always tier and takes that word, `[withheld]`** — the officer-block mechanism, and the only reading under which a suppression survives a binding with person names switched off *and* one with them on.
