# S7 · The producer suggests concepts from every sync

**Destination.** A sync over a published connected source extracts suggested concepts within its accepted cost estimate and the spending limit. It raises one suggestion set, whose summary names each new kind with its count, and records conflicts. An Admin renames or merges a kind from the Kinds list in one commit.

**Done when.**

- A sync over the website fixture raises a suggestion set, an Admin accepts it, and the api reads the concept with its evidence.
- Every claim in a suggested concept carries a locator into its document's normalised redacted text.
- A sync at the spending limit stops, and its refusal names who can raise the limit.
- Renaming a kind rewrites every affected `type` in one commit and re-keys `concept_identity`.

**Rests on.** ADR 0011, the minting rule. ADR 0012, acceptance before landing. ADR 0013, extraction gated apart from indexing. ADR 0026, kinds and their rename. ADR 0019, verifier and generator. ADR 0025, the `llm_call` row. ADR 0049, the model client. ADR 0005, two tiers.

Words: *producer*, *suggested concept*, *extraction template*, *cost estimate*, *spending limit*, *conflict*, *kind*, *Also known as*, *source entity*, *locator*, *model client*, *decision model*.

**Builds on.** Suggestions in `packages/core/src/concepts/suggestions.ts`, and their agreement in `contracts/suggestions/`. `foldKind` and `mergeKeyOf` in `packages/core/src/concepts/landing.ts`. The model client, model choice and spend in `packages/core/src/llm/` (#747, #749, #757).

**Must carry.**

- **Grounding.** A claim without a locator into the normalised redacted text is not a suggested concept. A search snippet is never evidence.
- **No extraction library.** langextract and contextgem are weighed and not adopted, because either adds a second path to a model (ADR 0049). The plan may take their techniques, character intervals and a split multi-pass.
- **The extraction target.** A sync adds sources to concepts, mints new ones and raises conflicts. It never edits a body or a status in place. A split is a supersession, and an alias is proposed as an *Also known as* line (ADR 0026).
- **Conflicts recorded.** The pipeline records both values with their evidence and never resolves one.
- **The extraction template.** There is one per document kind, versioned, and the cost estimate chooses it.
- **The generator on the file.** Every suggested concept names its producer, so its verifier is never its generator (ADR 0019).
- **Source entities.** A destination that includes the map yields source entities, never concepts (ADR 0011).
- **Credentials out of the model's reach.** No model call holds a connector's credential, which the sync decrypts per run (`docs/operations/SECRETS.md`).
- **Spend that settles.** A call's spend settles whatever happens to a member during it, under a workspace-scoped door in its own transaction (BA-186).

**Open for the plan.**

- **Which tier calls the model.** The model client is the api tier's, in TypeScript (ADR 0049), and the tiers share no code (ADR 0005). Either extraction is a job kind the api claims, as `JOB_KIND_DESCRIPTORS` allows, or the worker gains its own client and ADR 0049 is amended. A worker-side call needs its `llm_call` grants (BA-179).
- **Typed decisions for filing.** A decision model may answer which folder a suggested concept belongs in and whether it merges with a concept already there. Writing its text stays a generative model's. `crow-hq/llm-wiki-v2` routes such decisions through a decision model, and is read for patterns only, being AGPL-3.0-or-later (ADR 0027).

**Seams.** The model client's wire fake, in whichever tier's suite drives extraction. The document-shaped cross-tier test, from a sync to an accepted concept. The core slice interface for the rename. `contracts/` conformance. The browser suite for the Kinds list.
