# S7 · The producer suggests concepts from every sync

**Destination.** A sync over a published connected source extracts suggested concepts within its accepted cost estimate and the spending limit. It raises one suggestion set, whose summary names each new concept type with its count, and records conflicts. The Concept Types list offers no rename or merge (ADR 0026).

**Done when.**

- A sync over the website fixture raises a suggestion set, an Admin accepts it, and the api reads the concept with its evidence.
- Every claim in a suggested concept carries a locator into its document's normalised redacted text.
- A sync at the spending limit stops, and its refusal names who can raise the limit.

**Rests on.** ADRs 0005, 0011, 0012, 0013, 0019, 0025, 0026 and 0049.

**Builds on.**

- Suggestions in `packages/core/src/concepts/writes/suggestions.ts`, and their agreement in `contracts/suggestions/`.
- `foldConceptType` in `packages/core/src/bundle/index.ts`, and `mergeKeyOf` in `packages/core/src/concepts/import/landing.ts`.
- The model client, model choice and spend in `packages/core/src/llm/`.

**Must carry.**

- A search snippet is never evidence.
- langextract and contextgem are not adopted, because either adds a second path to a model. The plan may take their techniques: character intervals and a split multi-pass.
- A sync adds sources to concepts, mints concepts and raises conflicts, never editing a body or status in place. A split is a supersession, and an alias is proposed as an *Also known as* line.
- The pipeline records both values of a conflict with their evidence and never resolves one.
- There is one versioned extraction template per document kind, and the cost estimate chooses it.
- Every suggested concept names its producer, so its verifier is never its generator.
- A destination that includes the map yields source entities, never concepts.
- No model call holds a connector's credential, which the sync decrypts per run (`docs/operations/SECRETS.md`).
- A call's spend settles whatever happens to a member during it, under a workspace-scoped door in its own transaction (BA-186).

**Open for the plan.**

- Which tier calls the model. The model client is the api tier's, in TypeScript, and the tiers share no code. Either extraction is a job kind the api claims, as `JOB_KIND_DESCRIPTORS` allows, or the worker gains its own client and ADR 0049 is amended. A worker-side call needs its `llm_call` grants (BA-179).
- Whether a *decision model* picks a suggested concept's folder and whether it merges with an existing one, while a generative model writes its text. `crow-hq/llm-wiki-v2` routes such decisions through a decision model. It is AGPL-3.0-or-later, so read it for patterns only.
