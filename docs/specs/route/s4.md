# S4 · Website and SharePoint connected sources kept fresh

**Destination.** An Admin connects the first customer's website, one connected source per URL prefix, and a SharePoint library. Each is reviewed with its findings and a cost estimate, published, and synced on its cadence. A reader opens the source document behind a passage they may read.

**Done when.**

- A one-line edit to the website fixture re-indexes one passage on the next sync, and a gone document keeps only its cited evidence.
- A SharePoint library behind the Graph API fake is connected, reviewed, published and synced again.
- An Admin accepts a connected source's cost estimate once, on Cost estimates.
- The owner reads the step-A signal on the first customer's first index and records it under [the worker's box figures](../../operations/readings.md#the-workers-box-figures).

**Rests on.**

- ADR 0013, the connected source.
- ADR 0036, the sync's cocoindex blocks.
- ADR 0020, who opens an original.
- ADR 0024, one sync at a time and the step-A signal.
- ADR 0052, where a secret lives.
- ADR 0044, catalogue writes before passages.
- ADR 0027, a lift's licence.

**Words.** *connected source*, *connector*, *converter*, *sync*, *finding*, *cost estimate*, *retention class*, *citation fix*, *evidence panel*.

**Builds on.**

- The sync in `apps/worker/src/better_answers_worker/pipeline/`, with its converter (#87).
- Connect, review and publish in `packages/core/src/sources/`.
- `packages/schema/src/sources/source-tables.ts`, whose one connector is `upload`.

**Must carry.**

- **The estate-size probe.** A slim enumeration of the real site runs before any cost estimate is priced.
- **The cost estimate.** Review prices it from measured rates, and an Admin accepts it once. A sync that would reprocess more than a set share waits for the Admin to accept it again. The work it prices runs from S7.
- **The first index.** The first index runs one sync at a time, measured as its onboarding queue. Its memory signals are anonymous memory, `memory.swap.peak` and `pswpin`. A `memory.peak` at the cap that comes from page cache is not a failure.
- **Evidence outlives its source.** A gone document gets `gone_at`, and keeps its passages through mirror retention's grace period. A source that moved on raises a citation fix.
- **No skip on the hash alone.** A sync commits its catalogue writes before its passages, so an unchanged content hash alone never skips indexing a document.
- **One record per media type.** The worker's converter holds each media type's conversion and page rule together, so admitting HTML forces its page rule.
- **Job kinds from the descriptors.** The worker's `KINDS` is generated from `JOB_KIND_DESCRIPTORS` and checked both ways.
- **One reading of state.** A migration drops `connected_source.state`, which publish writes and nothing reads.
- **Connect apart from upload.** The second connector splits connecting a source from uploading its one document.
- **The redaction categories leave the DPIA module.** They leave `packages/core/src/sources/dpia.ts` when the findings module next changes.
- **The Graph credential.** The credential belongs to the workspace and goes to Microsoft Graph, so it is a sealed row, kept apart from Microsoft sign-in. This block builds it in the credentials provider.
- **Source viewing.** Where the source has a home, the evidence panel links out to it. For an upload, an Admin sets a switch per connected source, off by default. With the switch on, the source's audience opens the original in a viewer. With it off, the panel shows the whole redacted text. Every view of an original is an audit event. The build amends ADR 0020.
