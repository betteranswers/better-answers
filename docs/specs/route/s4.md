# S4 · Website and SharePoint connected sources kept fresh

**Destination.** An Admin connects the first customer's website, one connected source per URL prefix, and a SharePoint library. Each is reviewed with its findings, published, and synced on its cadence. A reader opens the source document behind a passage they may read.

**Done when.**

- A one-line edit to the website fixture re-indexes one passage on the next sync, and a gone document keeps only its cited evidence.
- A SharePoint library behind the Graph API fake is connected, reviewed, published and synced again.
- An Admin accepts a connected source's cost estimate once, on Cost estimates.
- The owner reads the step-A swap-in signal (`docs/operations/BACKUPS.md` § Signals) on the first customer's first index and records it under [the worker's box figures](../../operations/readings.md#the-workers-box-figures).

**Rests on.** ADRs 0013, 0020, 0024, 0027, 0036, 0044 and 0052.

**Builds on.**

- The sync and its converter in `apps/worker/src/better_answers_worker/pipeline/`.
- Connect, review and publish in `packages/core/src/sources/`.
- `packages/schema/src/sources/source-tables.ts`, whose one connector is `upload`.

**Must carry.**

- An estate-size probe, a slim enumeration of the real site, runs before any cost estimate is priced.
- Review prices the cost estimate from measured rates. A sync that would reprocess more than a set share waits for re-acceptance. The work it prices runs from S7.
- The first index runs one sync at a time, measured as its onboarding queue. Its memory signals are anonymous memory, `memory.swap.peak` and `pswpin`, and a page-cache `memory.peak` at the cap is not a failure.
- A gone document gets `gone_at` and keeps its passages through mirror retention's grace period. A source that moved on raises a citation fix.
- A sync commits catalogue writes before passages, so an unchanged content hash alone never skips indexing a document.
- The worker's converter holds each media type's conversion and page rule together, so admitting HTML forces its page rule.
- The worker's `KINDS` is generated from `JOB_KIND_DESCRIPTORS` and checked both ways.
- A migration drops `connected_source.state`, which publish writes and nothing reads.
- The second connector splits connecting a source from uploading its one document.
- The redaction categories leave `packages/core/src/sources/dpia.ts` when the findings module next changes.
- This block builds the Graph credential as a sealed workspace row in the credentials provider, apart from Microsoft sign-in.
- The evidence panel links to a source's home where it has one. For an upload, an Admin's per-source switch, off by default, lets its audience open the original in a viewer, and otherwise the panel shows the whole redacted text. Every view of an original is an audit event. The build amends ADR 0020.

**Open for the plan.**

- Whether a viewer opens at the cited place, since a locator carries no page.
- Which viewers to lift. The MIT-licensed viewers of `extend-hq/jevbox` are candidates.
