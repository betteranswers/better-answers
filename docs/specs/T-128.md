### Wave A — the four words and the route's status row (no code)

1. `CONTEXT.md` gains **chunk**, **locator**, **passage** and **landed copy**, each one definition with no implementation detail (`[GLOSSARY1]`), worded from the spec's *The words*:
   - *chunk* — one unit of a document's normalised, redacted text the index holds, keyed by its document and ordinal, carrying its binding's visibility.
   - *locator* — the address of a passage inside a source document: a span, `chars:<start>-<end>`, offsets in Unicode code points into the document's normalised redacted text, versioned by the redaction string that text carries. The string a citation's `sources[].locator` and a chunk's row both carry.
   - *passage* — the text a locator resolves to, served with its source's title and its sensitivity word; the unit `open` returns and a hit marked *Not company knowledge* previews.
   - *landed copy* — a document's bytes as the platform holds them in the object store: the original and the normalised redacted text under one document key.
   Placement: all four in **Knowledge model**, beside *evidence*, *source document*, *destination* and *retention class*; *passage* beside *locator* rather than in *Guides and answers*, where *unmapped passage* already leans on it.
