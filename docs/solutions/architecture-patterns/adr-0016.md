title: "An answer asserts concepts only, found by traversal and served as one verdict-first contract"
applies_when:
  - "Changing how an answer finds, reuses or drafts from concepts"
  - "Adding an endpoint or a transport that returns an answer"
  - "Changing the entry step's search or adding embeddings to it"
---

An answer asserts only what a concept states, found by traversal of the map from full-text entry points before any prose is written, and every fitting `Answer` concept comes back word for word, side by side, never blended. It is served as one event stream, verdict first, that one pure function folds into one object for the UI, MCP and the record. A sentence generated from document passages belongs to no knowledge layer, so no trust word can describe it, and once pasted into a tender it cannot be walked back.

## Rejected

- Drafting from documents when no concept answers: fluent prose nobody owns.
- Two contracts, one per transport: the drift one renderer exists to prevent.
- A cross-encoder reranker in v0.1: seconds per query on a CPU for a marginal gain.
