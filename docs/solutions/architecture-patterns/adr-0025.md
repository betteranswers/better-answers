status: accepted
title: "A signal is a query over rows the platform already keeps"
applies_when:
  - "Adding a signal, a threshold or an alert"
  - "Adding code that calls a model"
  - "Reaching for a metrics store, a scrape or a dashboard product"
---

A signal is a named query over rows the platform already keeps, such as `llm_call` and `backup`, and the platform runs no metrics store, scrape or dashboard product. A metrics store such as Prometheus with Grafana needs 0.5 to 1 GB of a 4 GB box and a second login, and a restore does not bring its signals back. Every model call writes one `llm_call` row with its tokens, seconds and priced cost, never the prompt or the completion, and the spending limit reads those rows.
