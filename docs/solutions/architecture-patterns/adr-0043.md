title: "An action admits before its first await and refuses in classed words across every transport"
applies_when:
  - "Adding an action to a slice in packages/core, or exposing one through tRPC, MCP or ops"
  - "Adding a refusal word, or mapping refusals onto a transport's errors"
---

An action is what an entry may ask core to do. Its hand-written face admits before its first `await`, a refusal word is declared once by its owning slice, classed by remedy and never removed or reclassed, and it crosses each transport as `{ word, class }` through one crossing function. Four problems were one absence: refusal words retyped per action, admission answered in three places, input stated per transport and three composition roads.

## Rejected

- A constructed action: the code index answered impacted 0, risk unknown, for a constructed face, so it cannot tell anyone what an edit breaks.
- A refusal as a value on the wire: every read page would branch on it, and a cached web app could do nothing with a word it had never met.
