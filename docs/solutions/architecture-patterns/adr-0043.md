status: accepted
title: "An action admits before its first await and refuses in classed words across every transport"
applies_when:
  - "Adding an action to a slice in packages/core, or exposing one through tRPC, MCP or ops"
  - "Adding a refusal word, or mapping refusals onto a transport's errors"
---

An action is what an entry may ask core to do. Three rules hold for every action:

- Its hand-written face admits the caller before its first `await`.
- Its owning slice declares each refusal word once and classes the word by its remedy. A word is never removed or reclassed.
- A refusal crosses every transport as `{ word, class }`, through one crossing function.

Before these rules, four problems had one cause. Each action retyped its refusal words. Three places answered admission. Each transport stated the input again. Actions were composed in three different ways.

## Rejected

- A constructed action. For a constructed face, the code index answered "impacted 0, risk unknown", so it cannot tell anyone what an edit breaks.
- A refusal sent as a value on the wire. Every read page would branch on it, and a cached web app could do nothing with a word it had never seen.
