title: "An action admits before its first await and refuses in classed words across every transport"
applies_when:
  - "Adding an action to a slice in packages/core, or exposing one through tRPC, MCP or ops"
  - "Adding a refusal word, or mapping refusals onto a transport's errors"
---

An action's hand-written face admits the caller before its first `await`, which the `action-admits-before-await` lint rule checks. Its slice declares each refusal word once, classed by its remedy, and never removes or reclasses a word. A refusal crosses every transport as `{ word, class }` through `refusalOf` in `apps/api/src/refusal.ts`. These rules replaced refusal words retyped in each action and admission decided in three places.

## Rejected

- An action built by a factory. The code index cannot say what an edit to it breaks.
