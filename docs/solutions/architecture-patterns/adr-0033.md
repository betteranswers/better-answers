title: "The interface is Tailwind v4 on the tokens; the registries own behaviour, the platform meaning"
applies_when:
  - "Building or styling a page in apps/web"
  - "Adding a component from shadcn, Kibo UI or AI Elements"
  - "Reaching for a component library or another UI dependency"
---

The interface uses Tailwind v4. Its theme comes from the design system's tokens through one bridge stylesheet. Components arrive as reviewed source from three shadcn registries: shadcn itself, Kibo UI, and AI Elements.

The registries own behaviour, which covers keyboard handling, focus, ARIA, and streaming. The platform owns meaning, which covers the trust words, the citation unit, and the glossary's vocabulary.

A second component set would drift from the first, because nothing ties the two together. A library that shipped its own severity palette would contradict ADR 0019's fixed trust words, and no check would notice.

## Rejected

- MUI, Mantine, or Chakra. Each one owns meaning as well as behaviour.
- Tailwind v3 with a config file. The config would be a second copy of the tokens, kept in sync by hand.
