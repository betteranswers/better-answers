  - "Building or styling a page in apps/web"

  - "Reaching for a component library or another UI dependency"
---

The interface uses Tailwind v4, themed from the tokens in `apps/web/src/styles/` through one bridge stylesheet. Components arrive as reviewed source from the shadcn, Kibo UI and AI Elements registries. The registries own behaviour: keyboard handling, focus, ARIA and streaming. The platform owns meaning: the trust words, the citation unit and the glossary's vocabulary.

## Rejected

- MUI, Mantine or Chakra. Each owns meaning as well as behaviour, such as its own severity palette, and nothing ties it to the tokens.
