  - "Building or styling a page in apps/web"

  - "Reaching for a component library or another UI dependency"

The interface is Tailwind v4 with its theme read from the design system's tokens through one bridge stylesheet, and components arrive as reviewed source from three shadcn registries. The registries own behaviour (keyboard, focus, ARIA, streaming) and the platform owns meaning (the trust words, the citation unit, the glossary's vocabulary). A second component set is drift by construction, and a library that shipped its own severity palette would quietly contradict ADR 0019's fixed trust words.

## Rejected

- MUI, Mantine or Chakra: each owns meaning as well as behaviour.
- Tailwind v3 with a config file: a second copy of the tokens, kept in sync by hand.
