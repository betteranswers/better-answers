status: accepted
title: "A person has one platform-minted id, carried on every Principal and every record the platform keeps"
applies_when:
  - "Naming a person on a record, an audit event or a commit"
  - "Minting an id in either tier"
  - "Writing an erasure step or declaring an audit action"
---

A person's one id is the id of their `user` row, minted by the platform's ULID minter, which Better Auth also uses as its `generateId`. It is `userId` on every `Principal`, and every record names the person as `human:<person id>`, except a concept file, which keeps `human:<email>`. A person named by several ids is joined by none of them.
