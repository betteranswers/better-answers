The platform has two runtime tiers. The TypeScript api owns everything a person or an agent touches, and it makes every policy decision. One Python worker turns sources into indexed, governed knowledge.

The two tiers share four stores: the Postgres schema, the object store, the git store, and the map. They share no code and make no HTTP calls to each other. The control plane is rows in the database. Because the contract between the tiers is data, a worker can run on another network with only a database connection string. A worker hosted by a customer needs exactly that.

## Rejected

- Forking Onyx or Dust. The parts the platform needs sit behind an Enterprise licence or are tied to the vendor's SaaS. Both projects also move at 500 to 1,400 commits a month.
- Rewriting the Python parts in TypeScript. That means rewriting Python-only libraries for no gain in v0.1, and the platform would still have two runtimes.
