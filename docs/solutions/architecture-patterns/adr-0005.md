The TypeScript api owns everything a person or an agent touches and makes every policy decision, and one Python worker turns sources into indexed knowledge with Python-only document libraries. The two tiers share four stores (Postgres, the map, the object store and the git store) but no code, make no HTTP calls to each other, and take work from job rows. Every agreement between them is data that both suites check in `contracts/`, so a worker can run on any network that reaches those stores, a customer's included.

## Rejected

- Forking Onyx or Dust. The parts the platform needs sit behind an Enterprise licence or are tied to the vendor's SaaS.
