The platform is two runtime tiers, a TypeScript api that owns everything a person or agent touches and every policy decision, and one Python worker that turns sources into indexed, governed knowledge. They share four stores, the Postgres schema, the object store, the git store and the map, and never code or HTTP, so the control plane is rows. A contract of data lets a worker run on another network with nothing but a database connection string, which a customer-hosted worker needs.

## Rejected

- Fork Onyx or Dust: Enterprise gates or SaaS entanglement on exactly the parts needed, and both move at 500 to 1,400 commits a month.
- Minimise Python by rewriting in TypeScript: rewrites Python-only libraries for no v0.1 gain and still leaves two runtimes.
