---
status: accepted
title: "A workspace's model key is sealed under the envelope key and opened only by the api at the moment of a call"
applies_when:
  - "Setting, reading or rotating a workspace's model key"
---

A workspace's model key is sealed under the envelope key, never hashed. The platform sends the key to the provider with every call, and a hash cannot be sent.

Only the api tier holds the envelope key, and it opens a model key at the moment of a call. The worker holds no grant on `model_key`. Setting a key is an audit event. Each read is accounted for by the call's `llm_call` row.

No command re-seals the model keys. After the envelope key changes, every workspace's model key must be set again. If the envelope key is compromised, every model key sealed under it must be reissued at its provider. Sealing the old key again is not enough.

## Rejected

- Hashing behind a lookup prefix, which is the shape the provider uses for tokens the platform checks. A hash cannot be sent to a provider.
