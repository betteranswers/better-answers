title: "One origin carries the product, the authorization server and the MCP surface"
applies_when:
  - "Adding an HTTP route, a path or a hostname to the ingress"
  - "Changing the session cookie, the trusted origins or the consent page"
---

One origin, `app.<apex>`, carries the SPA, sign-in, consent, `/oauth2/*`, `/.well-known/*` and `/mcp`, and `app.<apex>/mcp` is the protected-resource document's `resource` and every access token's audience. Two hosts sharing one session needed a cookie scoped to the apex, which sent the product's own bearer to every subdomain, including any a third party might one day serve. With no assistant credential yet, moving the issuer cost nothing, and later it would cost an assistant's connection.

## Rejected

- `mcp.` kept as a bearer-only resource host: a second document-serving host and a four-hostname fence for one path.
