status: accepted
title: "One origin carries the product, the authorization server and the MCP surface"
applies_when:
  - "Adding an HTTP route, a path or a hostname to the ingress"
  - "Changing the session cookie, the trusted origins or the consent page"
---

One origin, `app.<apex>`, serves the SPA, sign-in, consent, `/oauth2/*`, `/.well-known/*` and `/mcp`, and `app.<apex>/mcp` is the audience of every access token. A second host sharing the session would need a cookie scoped to the apex, which sends the session to every subdomain, including one a third party serves later. The origin is also the issuer, so moving it breaks every assistant's connection.
