title: "UI copy names the action or the fact and stops, in sentence case"
applies_when:
  - "Writing or changing text the web app shows: a label, heading, button, tab, table header, field, description, empty state, message or dialog"
  - "Adding or editing a words module under apps/web/src"
  - "Writing a browser spec, a component test or a verify recipe that finds a control or reads text on a page"
  - "Turning on the `better-answers/ui-copy-plain` rule for a folder"
---

The web app's copy names the action or the fact and stops. Labels, headings, buttons, tabs, table headers and fields are in sentence case: "Edit concept", not "Edit This Concept". A description is one sentence. A line of help appears only on an empty state or at first use, and an empty state names the next action. The page defines nothing, because definitions live in `GLOSSARY.md`, and it does not explain why something is absent. The trust words, the role names, the product name better-answers, and people's and workspaces' names stay as written. Tests and verify recipes find a control by its role and accessible name, and take the label from the words module, so a rewording breaks no test.

This decision replaces two rules of the archived plan of 13 October 2026 (`docs/plans/2026-10-13-1101-fix-web-wording-and-stock-refusals-plan.md`). KTD9 put headings, buttons, tabs and navigation in Title Case. R22 and KTD10 put a consequence line beside each button and a description under every dialog and empty state. The design readme carried both rules. Code and tests kept following them after the readme dropped them, and a later rewrite applied Title Case again. Specs, component tests and verify recipes copied the labels as literals, so a reworded label broke every test that named it, and the old words stayed.

## Rejected

- A rule that rewrites case automatically. KTD9 of the archived plan showed that it changes a person's or a workspace's name inside a label.
- A baseline file of today's violations. An override list that grows by folder is simpler, and it shrinks to one glob.
- Copy that defines a glossary word where the word appears. The definition goes stale, and the reader came to act.

## Consequences

- `better-answers/ui-copy-plain` enforces this decision in `apps/web/src`, with tests exempt. It refuses a label, any string with no sentence-ending full stop, that is not in sentence case. It also refuses a string that matches one of its banned patterns, such as "is one part of", and a string of more than two sentences or 25 words. Its allow-list comes from the proper nouns in `GLOSSARY.md`, the role names in `@better-answers/schema` and the trust words in `PRODUCT.md`.
- The rule is on only for the folders its override in `.oxlintrc.json` lists. Each copy sweep adds its folders when it rewrites them, and the last sweep replaces the list with `apps/web/src/**`.
- A spec or a component test imports a label from its words module, or finds the control by role and a short name. A sentence the page shows is asserted nowhere.
