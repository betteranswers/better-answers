status: accepted
title: "Better Answers is open core under Apache-2.0, and the hosted service is the product"
applies_when:
  - "Adding a dependency or lifting third-party code"
  - "Proposing a paid-only feature or an enterprise-licensed directory"
---

The repository is public under Apache-2.0. One licence covers the whole tree. There is no `ee/` directory and no feature held back for paying customers. What a customer pays for is the hosted service.

A dependency, or code lifted from another project, must be under MIT, BSD, ISC, Apache-2.0, or the PostgreSQL licence. Copyleft software runs unmodified as a separate process that the platform reaches over a network protocol. The platform never links copyleft code or copies it into the tree.

The product's one claim that no competitor makes is an open format the customer owns. That claim holds only if the customer can leave with the bundle and run the software that reads it. The share agent is sold to people who read its source before they install it.

The project picked Apache-2.0 over MIT for its patent grant and because it reserves the project's name. The name has no registered trade mark.

## Rejected

- A source-available licence, such as the Business Source Licence or the Functional Source Licence. The product could no longer call itself open, and every customer's legal team would have to review a bespoke licence.
- AGPL-3.0. An IT manager would refuse to install the share agent, and the licence would guard against a competitor that does not exist yet.
- An `ee/` directory for paid features. It doubles every seam. Every feature worth gating is also part of what makes the product usable.
