The one MCP server offers four tools, `find`, `ask`, `open` and `give_feedback`, and takes the Principal and the workspace from the token, so no tool takes a workspace. Capability grows by token scope, never by more tools or a second server. The predecessor grew to fifty-eight curation tools, while the outcomes that mattered came from reading.

## Rejected

- One tool per record family. Payloads double, and counts computed across tools leak what a reader may not see.
- Resources for concepts and guides. claude.ai supports tools first.
