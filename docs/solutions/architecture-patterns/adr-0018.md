The MCP surface is four tools-only entries, `find`, `ask`, `open` and `give_feedback`, on one server. The Principal and the workspace come from the token, so no entry takes a workspace, and capability grows by token scope, never by a second server. The predecessor's fifty-eight-tool surface showed what accretion does, tools built for curation under outcomes built on consumption, and long or scheduled work belongs to headless agents reading through these same entries.

## Rejected

- Eight tools, one per record family: doubles payloads, leaks "cited in N" by arithmetic, and carries a question-set task a stateless server cannot serve.
- Resources for concepts and guides: claude.ai's support is tools-first.
- A second server for acting: two of everything for the same person.
