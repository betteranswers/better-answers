The MCP server offers four entries, all of them tools: `find`, `ask`, `open`, and `give_feedback`. There is one server. The Principal and the workspace come from the token, so no entry takes a workspace. Capability grows by token scope and never by a second server.

The predecessor grew to fifty-eight tools. They were built for curation, while the outcomes that mattered came from consumption. Long or scheduled work belongs to headless agents that read through these same four entries.

## Rejected

- Eight tools, one per record family. Payloads double, arithmetic across tools leaks "cited in N", and one of the tools carries a question-set task that a stateless server cannot serve.
- Resources for concepts and guides. claude.ai supports tools first.
- A second server for acting. The same person would get two of everything.
