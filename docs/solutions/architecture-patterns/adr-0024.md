  - "A workspace asks for a local embedding model choice"

The forge is bare git repositories under `GIT_STORE_DIR`, one per workspace, written by the api through the git binary with no forge service, and v0.1 runs on two boxes of 4 vCPU and 4 GB that cannot be resized. The api is the only committer with no human accounts, so Forgejo's UI, SSH server and user model ran for nobody. Cash is tight before the first customer pays, so a model-host box waits for the first workspace that asks for local embedding.

## Rejected

- Keeping Forgejo: it fits, but it would be a service to patch, drill, back up and mirror for no one.
- A git library inside the api: a customer-hosted worker cannot mount a shared volume.
