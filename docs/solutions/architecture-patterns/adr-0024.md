  - "A workspace asks for a local embedding model choice"

The forge is a set of bare git repositories under `GIT_STORE_DIR`, one for each workspace. The api writes them through the git binary, and no forge service runs. In v0.1 the platform runs on two boxes, each with 4 vCPU and 4 GB of memory, and neither box can be resized.

The api is the only committer and there are no human accounts, so Forgejo's UI, SSH server, and user model ran for nobody. Cash is tight until the first customer pays. A box to host models waits for the first workspace that asks for a local embedding model.

## Rejected

- Keeping Forgejo. It fits on the box, but it would be one more service to patch, drill, back up, and mirror, for no user.
- A git library inside the api. A worker hosted by a customer cannot mount a shared volume.
