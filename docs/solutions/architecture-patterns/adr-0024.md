title: "The forge is bare git repositories the api writes, on two 4 GB boxes"
applies_when:
  - "Writing to or reading from a workspace's git repository"
  - "Adding a service to either box, or changing the worker's memory cap"
---

The forge is one bare git repository per workspace under `GIT_STORE_DIR`, written by the api through the `git` binary, and no forge service runs. The api is the only committer and no person has an account, so Forgejo's UI, SSH server and user model would be one more service to patch, back up and mirror for nobody. v0.1 runs on two boxes of 4 vCPU and 4 GB that cannot be resized, so every service's memory limit is counted in `docs/operations/coolify.md`.
