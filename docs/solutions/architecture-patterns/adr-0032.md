The map is two ordinary tenant tables, `map_node` and `map_edge`, traversed by a prepared recursive-CTE template capped at depth 4, with no Apache AGE, no neo4j ecosystem and no per-workspace role. Every tenant table is created `withRLS()` under `FORCE ROW LEVEL SECURITY`, and a table with no policy returns no rows. AGE stored each workspace's map as its own schema, and row-level security guards rows, not schemas, so fifty maps needed fifty roles.

## Rejected

- Keeping AGE and spiking first: the spike defends a convenience whose induced cost is larger whatever the spike measures.
- An edges table with per-workspace roles kept: catalogue sprawl, and `pg_dump` does not carry roles.
