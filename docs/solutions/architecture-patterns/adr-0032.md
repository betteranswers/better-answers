title: "The map is plain Postgres tables, and row-level security is the tenancy guarantee"
applies_when:
  - "Adding a tenant table, a grant, a policy or a definer function"
  - "Writing a map traversal, or proposing a graph engine or database"
---

The map is two ordinary tenant tables, `map_node` and `map_edge`, walked by a prepared recursive CTE that `MAP_WALK_DEPTH` caps at depth 4. Every tenant table is created with `withRLS()` and runs under `FORCE ROW LEVEL SECURITY`, so a table with no policy returns no rows. Apache AGE kept each workspace's map in its own schema, and row-level security guards rows, not schemas, so AGE needed a role per workspace, and `pg_dump` does not carry roles.
