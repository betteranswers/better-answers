The map is two ordinary tenant tables, `map_node` and `map_edge`. A prepared recursive-CTE template walks them, and `MAP_WALK_DEPTH` caps the walk at depth 4. The map uses no Apache AGE, nothing from the neo4j ecosystem, and no role per workspace.

Every tenant table is created with `withRLS()` and runs under `FORCE ROW LEVEL SECURITY`. A table with no policy returns no rows.

AGE stored each workspace's map in its own schema. Row-level security guards rows, not schemas, so fifty maps needed fifty roles.

## Rejected

- Keeping AGE and running a spike first. The spike would defend a convenience. The cost that AGE brings is larger than anything the spike could measure.
- An edges table that keeps the per-workspace roles. The roles fill the catalogue, and `pg_dump` does not carry roles.
