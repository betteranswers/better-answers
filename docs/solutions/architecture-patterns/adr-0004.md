---
status: accepted
title: "Guides and write-ups are platform records that cite concepts and never restate them"
applies_when:
  - "Adding a guide, a section, a write-up or a response"
  - "Deciding whether a new key belongs in a concept file or in a platform record"
---

Guide definitions and write-ups are platform records in Postgres with append-only versions, and they cite concepts by IRI without restating them. Prose stored as a concept file would drift from the concepts under it and fill the bundle with one interface's state. A governed commit writes each guide's skeleton, which holds no prose, to `guides/<guide id>.yaml` in the workspace repository, so the guide's structure stays with the customer if they leave the platform.
