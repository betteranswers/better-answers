---
status: accepted
title: "Guides and write-ups are platform records that cite concepts and never restate them"
applies_when:
  - "Adding a guide, a section, a write-up or a response"
  - "Deciding whether a new key belongs in a concept file or in a platform record"
---

A guide definition and every write-up are platform records in Postgres with append-only versions, citing concepts by IRI and never restating them, while the platform writes each guide's prose-free skeleton into the workspace repository at `guides/<guide id>.yaml` as a governed commit. Guides are product functionality over knowledge, not knowledge, and generated prose stored as a file drifts by design. The skeleton keeps the promise that the map's structure outlives the tool.

## Rejected

- Narrator concepts in the bundle: prose drifts, the bundle carries per-product UI state, and guides become git workflow for people.
- Database only, with no skeleton projection: gives up the structural portability no competitor offers.
