title: "The MCP surface is MCP SDK v2 in apps/api, behind one fetch-shaped seam"
applies_when:
  - "Changing the MCP surface, its entries or the library under it"
  - "Proposing FastMCP, a Python MCP server or an MCP App framework"
  - "Proposing an outbound connector, a sync or a write into a system that is not a connected source"
---

The MCP surface is `@modelcontextprotocol/server` in `apps/api`, behind `createMcpSurface`, one fetch-shaped seam that verifies the bearer token and runs each entry under a `Principal`. The seam makes the SDK cheap to replace, but the surface stays in the api tier, where the `Principal` and the read predicate live. FastMCP, which is Python-only, offers an OAuth proxy, and the platform has no use for one because it is its own authorization server.

The platform builds no connector into a system that is not a connected source. The Claude platform reaches those systems through the person's own MCP servers, with credentials Better Answers never holds.
