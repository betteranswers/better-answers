---
status: accepted
title: "The model client is one fetch-shaped seam with a registry of wire shapes"
applies_when:
  - "Calling a model from the api tier, for any purpose"
  - "Adding a provider, a model host or a wire shape a model choice can name"
  - "Proposing a provider's SDK, a gateway library or a second path to a model"
  - "Testing code that calls a model"
---

Every model call from the api tier goes through one fetch-shaped seam in `packages/core/src/llm`, with a registry that maps each provider to a wire shape. The caller injects `fetch`, so a test fakes the wire and never the platform's code. No provider SDK or gateway library is added, because each would be a second path to a model and a mocked SDK tests only the mock. A failed call never falls back to another model, because that would be a judgement nobody chose at a price nobody set.
