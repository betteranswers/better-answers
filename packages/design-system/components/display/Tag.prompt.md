One-line: a chip for a kind, a domain or a filter in force — neutral by default; a tone only where the word already says the same thing.

```jsx
<Tag>Answer</Tag>
<Tag tone="accent" size="sm">Product</Tag>
<Tag onRemove={clear}>Sensitivity: Restricted</Tag>
```

Never use a Tag for trust — that is `TrustTag`, whose words are fixed.
