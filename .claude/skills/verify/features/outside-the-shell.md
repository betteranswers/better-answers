# Outside the shell

Sign in, display name, no workspace, account, second factor, recovery, workspace picker, invitation, Claude's consent, the not-found page.

`<stamp>` is `date +%s`, taken once for this file. `<email%>` is an address with `@` written as `%40`.

## Sign in by hand

For `<address>`, client address `198.19.3.<n>` and landing page `<landing>`.

1. `.claude/skills/verify/scripts/browse.sh <port> cookies clear`, `.claude/skills/verify/scripts/browse.sh <port> set headers '{"cf-connecting-ip":"198.19.3.<n>"}'`, `.claude/skills/verify/scripts/browse.sh <port> open http://localhost:<port>/sign-in`, `.claude/skills/verify/scripts/browse.sh <port> wait --fn "document.querySelector('input[type=email]') !== null"`, `.claude/skills/verify/scripts/browse.sh <port> find role textbox fill "<address>" --name "email"`, `.claude/skills/verify/scripts/browse.sh <port> find role button click --name "send"`, `.claude/skills/verify/scripts/browse.sh <port> wait --fn "document.querySelector('input[autocomplete=one-time-code]') !== null"`.
2. `.claude/skills/verify/scripts/harness.sh <port> GET "/codes?email=<email%>"` answers `code`. Then `.claude/skills/verify/scripts/browse.sh <port> find role textbox fill "<code>" --name "code"`, `.claude/skills/verify/scripts/browse.sh <port> wait --fn "location.pathname === '<landing>'"`.

Make an authenticator code from a key by running `node --input-type=module -e "import { authenticatorCodeAt } from './packages/schema/test/people/authenticator-code.ts'; console.log(authenticatorCodeAt(process.argv[1], new Date()));" <key>` as a command of its own, and type the code within the same half minute.

Then `.claude/skills/verify/scripts/browse.sh <port> find role textbox fill "<shortName>" --name "short name"`, `.claude/skills/verify/scripts/browse.sh <port> find role textbox fill "I run the joinery team." --name "reason"`, `.claude/skills/verify/scripts/browse.sh <port> find role button click --name "join"`, `.claude/skills/verify/scripts/browse.sh <port> wait --fn "/request sent/i.test(document.body.innerText)"`.

Expect the authenticator section to say an authenticator is set up, the recovery codes section to show `10 of 10` codes left, and the sessions section to list this device as active now.
