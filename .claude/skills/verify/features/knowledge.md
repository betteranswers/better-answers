# Knowledge

Search the workspace's concepts, read one, read a guide, browse the concepts by collection and type, name a collection's owner, curate every concept, count the concept types, download the exports.

Two setups serve the recipes. The Northbridge set, seeded by one script, serves *knowledge-search* and *knowledge-concept*. The Verify Knowledge setup serves the recipes after them, and each recipe that needs other data says so. Run each setup once, in a fresh workspace, then its recipes in order.

## Setup: the Northbridge set

It prints the workspace, the Admin, Editor and Viewer emails, one line per concept as `<title>`, `<iri>` and `<page path>` separated by tabs, and the concepts in each state. Every run makes a new workspace and new emails, so a second run never collides. `<admin.email>`, `<editor.email>` and `<viewer.email>` are the `admin`, `editor` and `viewer` lines, and `<page path of X>` is the last column of the line for *X*.
